# 💳 Controle de Compras com Cartão de Crédito 

## 🎓 Contexto do Projeto

Este projeto foi desenvolvido como **desafio do curso de Programação Orientada a Objetos**, integrante da **trilha de back-end do Programa Oracle Next Education (ONE)** — uma iniciativa da **Oracle em parceria com a Alura**.

O objetivo do desafio é consolidar os principais conceitos de **Orientação a Objetos em Java**, aplicando-os na construção de uma aplicação funcional, organizada e interativa via console.

## 📌 Descrição do Projeto

A aplicação permite o controle de compras realizadas com um cartão de crédito, onde o **limite é definido pelo usuário**.  
O sistema possibilita lançar compras, consultar limite disponível, visualizar o faturamento e exibir o histórico de compras ao encerrar o programa.


## 🎯 Objetivo do Desafio

Desenvolver uma aplicação que permita:

- Definir o limite inicial de um cartão de crédito
- Registrar compras respeitando o limite disponível
- Exibir informações do cartão e das compras realizadas
- Listar as compras realizadas ao encerrar o programa
- Aplicar conceitos fundamentais de **Programação Orientada a Objetos em Java**

## ▶️ Como Executar

1. Certifique-se de ter o **Java 17+** (ou compatível) instalado
2. Clone o repositório ou copie os arquivos
3. Compile o projeto:
   ```bash
   javac br/com/alura/Main.java
   ```

4. Execute:

   ```bash
   java br.com.alura.Main
   ```
